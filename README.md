## 🛠️ Tecnologías y Herramientas

- **React & Vite** para la estructura y rendimiento óptimo.
- **Tailwind CSS** para el diseño responsivo y estilos avanzados.
- **Framer Motion** para transiciones y animaciones fluidas.
- **Canvas API** para el sistema personalizado de estrellas y estrellas fugaces en el fondo.
